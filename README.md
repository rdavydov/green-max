# GREEN MAX

Небольшой чат на React и TypeScript для отправки и получения текстовых сообщений в MAX через [GREEN-API](https://green-api.com/max). За основу интерфейса взята [веб-версия MAX](https://web.max.ru/).

[Открыть приложение](https://rdavydov.github.io/green-max/) · [Локальный запуск](#локальный-запуск) · [Скриншоты](#скриншоты)

## Локальный запуск

Нужны Node.js 24 LTS и npm.

```sh
git clone https://github.com/rdavydov/green-max.git
cd green-max
npm ci
npm run dev
```

Откройте [http://localhost:5173/](http://localhost:5173/). Если порт занят, Vite выведет другой адрес в терминале.

По умолчанию запросы идут на `https://api.green-api.com/v3`. Чтобы использовать другой адрес API, создайте `.env.local` рядом с `package.json`:

```dotenv
VITE_GREEN_API_URL=https://api.green-api.com/v3
```

После изменения адреса перезапустите dev-сервер или заново соберите проект. Ключи в `.env.local` добавлять не нужно: `idInstance` и `apiTokenInstance` вводятся на экране подключения.

Проверка готовой сборки:

```sh
npm run build
npm run preview
```

Адрес для preview — [http://localhost:4173/green-max/](http://localhost:4173/green-max/).

## Настройка GREEN-API

Создайте MAX-инстанс в [личном кабинете](https://console.green-api.com/) и авторизуйте аккаунт MAX. Затем откройте инстанс, найдите раздел **Уведомления / Webhooks** и нажмите **Изменить / Change** рядом с ним.

Названия полей в кабинете отличаются от названий в документации API:

| Поле в русском кабинете | Поле в английском кабинете | Что выбрать | Параметр API |
| --- | --- | --- | --- |
| Адрес отправки уведомлений (URL) | Webhook Url | Оставить пустым | `webhookUrl` |
| Получать уведомления о входящих сообщениях и файлах | Receive webhooks on incoming messages and files | Включить | `incomingWebhook` |
| Получать уведомления о статусах отправленных сообщений | Receive webhooks on sent messages statuses | Включить | `outgoingWebhook` |
| Получать уведомления о сообщениях, отправленных с API | Receive webhooks on messages sent from API | Включить | `outgoingAPIMessageWebhook` |
| Получать уведомления о сообщениях, отправленных с телефона | Receive webhooks on messages sent from phone | Включить | `outgoingMessageWebhook` |

Сохраните настройки и подождите до 5 минут. Приложение само настройки инстанса не меняет. При входе оно проверяет авторизацию, тип MAX-инстанса, входящие уведомления и пустой адрес Webhook.

Входящие уведомления нужны для новых ответов. Уведомления о статусах и исходящих сообщениях позволяют показывать отправку, доставку и прочтение, а также сообщения из MAX на телефоне или компьютере. Названия в таблице сверены с русской и английской версиями кабинета GREEN-API.

## Как пользоваться

1. Откройте [приложение](https://rdavydov.github.io/green-max/), введите `idInstance` и `apiTokenInstance` из кабинета и нажмите «Подключиться».
2. Выберите существующий чат или нажмите «Новый чат» и введите номер получателя. Поддерживаются номера России (`+7`) и Беларуси (`+375`); пробелы, скобки и дефисы можно оставить.
3. Напишите сообщение и нажмите Enter или кнопку отправки. Shift+Enter добавляет новую строку. Лимит — 4000 символов.

При входе загружается список личных чатов MAX. При открытии чата приложение запрашивает последние 100 сообщений и показывает текстовые. Сообщения самому себе находятся в «Избранном». На телефоне список и переписка открываются отдельными экранами.

Если поиск по номеру запрещён настройками приватности получателя, создать чат по телефону не получится.

## История и статусы

Чаты и сообщения сохраняются в браузере отдельно для каждого инстанса. После обновления страницы нужно снова ввести ключи, но локальная переписка останется. Удаление данных сайта удалит эту копию истории. Старые сообщения за пределами последних 100 записей приложение автоматически не загружает.

«В очереди» означает, что GREEN-API принял сообщение. «Отправлено» появляется после подтверждения отправки в MAX. «Доставлено» и «Прочитано» приходят из уведомлений или истории. Если уведомления выключены, новый статус можно получить при следующей загрузке истории чата.

При сетевой ошибке текст остаётся в поле. Повторно отправить его можно вручную, проверив перед этим чат в MAX: сервер мог принять сообщение до обрыва соединения.

Токен хранится только в памяти вкладки. В localStorage и сборку он не записывается. Запросы выполняются прямо из браузера.

Для одного инстанса может быть активна одна вкладка приложения. Нужен браузер с Web Locks API и HTTPS или localhost. Не запускайте другое приложение, которое одновременно забирает уведомления этого же инстанса.

Полученные сообщения сохраняются до удаления уведомления из очереди GREEN-API. Повторы не создают дубликаты. Если сохранить историю не удалось, получение останавливается; при временном сетевом сбое приложение переподключается.

Группы, вложения, звонки, редактирование и удаление сообщений в этом проекте не реализованы.

## Проверки

```sh
npm run typecheck
npm run lint
npm test
npx playwright install --no-shell chromium
npm run test:e2e
npm run build
```

Vitest и Testing Library проверяют формы, API-клиент, хранение истории и обработку уведомлений. Playwright проверяет обмен сообщениями, чаты, статусы, ошибки, перезагрузку и две вкладки. Размеры экранов — 1440×900 и 360×780. Запросы GREEN-API в тестах подменяются, реальные сообщения они не отправляют.

Результат проверки с настоящим MAX-инстансом записан отдельно в [docs/manual-check.md](docs/manual-check.md).

## Публикация

[GitHub Actions](.github/workflows/deploy.yml) проверяет типы, lint, тесты и сборку. Успешная сборка из `main` публикуется на GitHub Pages; pull request проходит только проверки.

Для своего репозитория выберите **Settings → Pages → Build and deployment → Source: GitHub Actions**. В `vite.config.ts` указан путь `/green-max/`; при другом имени репозитория его нужно изменить. Ключи GREEN-API для сборки и CI не нужны.

## Стек и API

React, TypeScript, Vite, CSS. Для тестов — Vitest, Testing Library и Playwright. Собственного сервера и SDK нет, для HTTP-запросов используется `fetch`.

Методы GREEN-API: [SendMessage](https://green-api.com/v3/docs/api/sending/SendMessage/), [GetChats](https://green-api.com/v3/docs/api/service/GetChats/), [GetChatHistory](https://green-api.com/v3/docs/api/journals/GetChatHistory/), [получение уведомлений через HTTP API](https://green-api.com/v3/docs/api/receiving/technology-http-api/), [настройки инстанса](https://green-api.com/v3/docs/api/account/SetSettings/).
