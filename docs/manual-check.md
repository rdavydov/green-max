# Проверка с настоящим MAX

## 8 октября 2026

Пользователь вошёл в опубликованное приложение с ключами своего MAX-инстанса и отправил текст самому себе. Сообщение появилось в MAX в чате «Избранное». Результат подтверждён пользователем.

В этой проверке нашлись две проблемы: существующие чаты не загружались, а отправленное сообщение оставалось со статусом «В очереди» в приложении.

После публикации исправлений пользователь обновил страницу, вошёл повторно и подтвердил: существующие личные чаты появились, статус ранее отправленного сообщения исправился.

Входящий ответ от другого аккаунта и переходы «Доставлено» / «Прочитано» на реальном инстансе ещё предстоит проверить. Автоматические тесты используют подменённые ответы API.
